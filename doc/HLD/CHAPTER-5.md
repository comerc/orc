# Глава 5. Экосистема и Интеграции: Универсальный Хост

## 5.1. Почему не стоит писать свои коннекторы

Традиционный подход (n8n, Zapier) — это «гонка вооружений». Вам нужно написать и поддерживать 1000 интеграций: Slack, Gmail, Salesforce... Это тупик для новой платформы.
В 2026 году побеждает тот, кто использует стандарты.

---

## 5.2. MCP (Model Context Protocol) — «Руки» Агента

Протокол от Anthropic стал стандартом де-факто.

- **Как это работает:** Вместо того чтобы писать код для Slack API, вы просто подключаете к своему движку **MCP-сервер Slack**.
- **Преимущество:** Наш продукт мгновенно получает совместимость с сотнями инструментов, которые пишет мировое сообщество.
- **Реализация:** Наш Go-движок выступает в роли **MCP Client**. Мы пробрасываем инструменты (Tools) прямо в контекст агента.

## 5.3. A2A (Agent-to-Agent) — «Команда» Агентов

Для сложных задач одного агента мало. Нужно нанимать «подрядчиков».

- **Сценарий:** Наш агент (Менеджер) находит во внешнем каталоге (Directory) узкоспециализированного агента (Юриста) и поручает ему задачу.
- **Протокол:** Мы реализуем поддержку стандартных протоколов взаимодействия (Agent Protocol).
- **Ценность:** Наша платформа становится **Оркестратором Оркестраторов**. Мы не просто запускаем код, мы управляем взаимодействием разнородных ИИ-сущностей, гарантируя надежность их общения через наш Durable Log.

## 5.4. OpenAPI (Swagger) — «Глаза» Агента

Для работы с корпоративным софтом (SaaS).

- **Авто-генерация:** Пользователь дает ссылку на Swagger/OpenAPI спецификацию своего сервиса.
- **Магия:** Наша платформа на лету генерирует набор Tool Definitions для LLM. Агент сразу «понимает», как дергать ручки API этого сервиса.

# Глава 6. Бизнес-модель и Go-to-Market

## 6.1. Что мы продаем?

Мы не продаем «еще один движок». Мы продаем **Уверенность**.

- **Продукт:** Enterprise AI Automation Platform.
- **Ценностное предложение:** «Ваши ИИ-агенты будут работать надежно, как банковские транзакции. С полным аудитом и контролем бюджета».

## 6.2. Монетизация

1.  **Managed SaaS (Cloud):** Подписка за время выполнения (vCPU/hour) и объем логов. Легкий вход для стартапов.
2.  **Enterprise License (Self-hosted):** Для банков и крупных корпораций, которые хотят держать данные у себя. Лицензия на ядра + премиум-поддержка.
3.  **Consulting & Solutions:** Самая прибыльная часть на старте. Мы используем свою платформу, чтобы быстро собирать кастомные решения для клиентов. Платформа — это наш «секретный соус», позволяющий демпинговать по срокам разработки.

## 6.3. Стратегия Open Source (OSS)

Мы открываем ядро (Community Edition).

- **Зачем:** Чтобы завоевать доверие разработчиков (No vendor lock-in) и получить бесплатное тестирование/контрибьюшн.
- **Ограничения:** В бесплатной версии нет SSO, RBAC (ролей), расширенного аудита и некоторых Enterprise-коннекторов.
- **Цель:** Стать стандартом индустрии («GitLab для ИИ-агентов»), на котором учатся, чтобы потом купить Enterprise-версию для продакшена.

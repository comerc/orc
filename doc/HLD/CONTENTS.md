# Vision & Architecture (High-Level Design)

## Оглавление

**Глава 1. Выбор Ядра: Почему Restate на Go?**

- **Дилемма 2026:** Человек (Hatchet/DAG) против Агента (Restate/Code). Почему для Agentic AI код гибче схемы.
- **Архитектурный донор:** Переход от монолита (Windmill Core) к легкому прокси (Restate-style).
- **Технический базис:** Event Sourcing, Virtual Objects и решение проблемы консистентности (Log-based state).
- **Сравнение:** Глубокий разбор vs Temporal (сложность), vs Hatchet (жесткость), vs Inngest (пуш-модель).

**Глава 2. Паттерны Надежности и Транзакции**

- **Saga Pattern для ИИ:** Почему классические транзакции не работают с LLM. Реализация стека компенсаций (Orchestrated Saga).
- **Входные ворота:** Эволюция от Ingress SDK к AI Gateway. Идемпотентность и кэширование до запуска воркфлоу.
- **Durable Streams:** Разделение ответственности — надежность исполнения (Backend) vs надежность доставки (UI Stream).

**Глава 3. Среда Исполнения (Runtime): Стратегия "Полиглот"**

- **Проблема:** Restate не исполняет код. Нам нужен свой Runner.
- **Решение из Windmill:** Поддержка TS, Python и Go через изоляцию.
- **Технологии:**
  - _Lite:_ Wasm/Wazero (мгновенный старт, безопасно).
  - _Standard:_ Docker SDK (DooD) для тяжелых Python-агентов.
  - _External:_ A2A Directory (запуск чужих агентов без хостинга).

**Глава 4. Интерфейс Платформы (UI/UX)**

- **Наследие Windmill:** Flow Builder (визуализация кода), Auto-forms (генерация UI из схемы).
- **AI-специфика:** Чат-режим для агентов, дерево рассуждений (Reasoning Tree).
- **Human-in-the-loop:** Узлы одобрения, использующие механизм «Durable Sleep» ядра.

**Глава 5. Экосистема и Интеграции**

- **Отказ от велосипедов:** Стратегия «Universal Host».
- **Стандарты:** MCP (для инструментов), OpenAPI (для SaaS), A2A (для агентов).

**Глава 6. Бизнес-модель и Go-to-Market**

- **Продукт:** Enterprise SaaS + Custom Development.
- **OSS стратегия:** Self-hosted версия для продвижения и комьюнити (аналог Gitlab CE).
- **Киллер-фичи:** Traceability (аудит мыслей), Cost Control (фин. квоты), Security (приземление воркеров).
